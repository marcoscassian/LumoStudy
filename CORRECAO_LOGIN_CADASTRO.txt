LumoStudy - correção de cadastro/login

Alterações principais:
- backend/.env criado para MySQL local localhost:3306, usuário root e senha admin.
- frontend/.env.local criado apontando para http://127.0.0.1:8000.
- Cadastro agora trata erros de conexão e erros de validação do FastAPI sem tentar renderizar objetos React.
- Nome mínimo de 2 caracteres e senha mínima de 6 caracteres no formulário.
- Login normaliza o e-mail antes de enviar.
- Validação de senha do backend não gera erro 500 se houver hash antigo/corrompido.
- .env.example teve credenciais sensíveis removidas/substituídas por placeholders.

Para rodar:
1) Backend:
   cd backend
   python -m venv env
   env\Scripts\activate
   pip install -r requirements.txt
   python main.py

2) Frontend (em outro terminal):
   cd frontend
   npm install
   npm run dev

Abra http://localhost:3000
